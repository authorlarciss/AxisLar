# ADR-0008: Раскладка тестов — ось модуль, уровень маркером

## Контекст

Шаблон поставлял тесты в `tau/unit/` и `tau/integration/`, то есть
раскладывал их по уровню. Первый же downstream-проект (VaultLar) добавил
рядом `tau/beta/`, `tau/delta/`, `tau/gamma/`, `tau/e2e/`: раскладка
поехала по двум осям одновременно. Результат: один и тот же тест можно
положить в два места, никто не знает, где он должен быть, а «где лежит
тест моего модуля» решается поиском.

Уровень — свойство прогона (быстро/медленно, с внешними границами/без),
а не место жительства файла. Модуль — граница контракта, владелец кода и
единица покрытия.

## Решение

1. **Каталог = модуль:** `tau/<module>/test_<что>.py`. Корневые
   `tau/unit/` и `tau/integration/` запрещены.
2. **Уровень = маркер:** `unit` (по умолчанию), `integration`, `contract`,
   `e2e`, `template`. Авто-маркировка по каталогу в `tau/conftest.py`;
   файл может выставить свой уровень (`pytestmark = pytest.mark.integration`).
3. **Легальные каталоги без модуля-владельца:** `tau/contract/`,
   `tau/e2e/`, `tau/support/`, `tau/template/`, `tau/eta/` — они
   тестируют отношения между модулями или обслуживают репозиторий.
4. **Раскладка проверяется машинно:** `tau/template/test_layout.py`
   падает на запрещённых каталогах, на каталоге без владельца и на
   тестах в корне `tau/`.
5. **`tau/template/` — обвязка шаблона:** сносится `make strip-template`
   вместе с маркером `template` в `pyproject.toml`.

## Альтернативы

- **Только уровни** (`tau/unit`, `tau/integration`, `tau/e2e`). Работает,
  пока тестов десятки; при росте «где тесты delta» ищется по содержимому.
  Отклонено: масштабируется хуже и уже один раз привёл к смешению.
- **Только модули, без уровней.** Медленные и быстрые тесты в одном
  каталоге, нельзя прогнать быстрый поднабор. Отклонено.
- **Двойная вложенность** `tau/<module>/unit/`, `tau/<module>/integration/`.
  Каталог-на-модуль, каталог-на-уровень внутри — то же смешение, но
  глубже; плюс пустые каталоги. Отклонено.

## Последствия

Плюсы: однозначное место для нового теста; `make test-module M=beta`
запускает тесты модуля с покрытием только его; раскладка не разъезжается
без падения теста.

Минусы: фильтрация по уровню требует дисциплины маркеров (частично
автоматизирована); тесты, тестирующие два модуля сразу, приходится класть
в `tau/psi/` (композиция) или в `tau/contract/`, а не в каталог одного из
модулей; `tau/eta/` — второе (после `template`) исключение из правила
«каталог = модуль».

## Статус

Принято.
