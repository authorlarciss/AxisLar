# Omega — сборка и релиз

Директория содержит **операционные** артефакты: то, что нужно, чтобы
собрать и выкатить проект. Инструменты разработки (линтеры-генераторы,
форк-скрипты) живут в `eta/` — они запускаются в `make check` и в
артефакты релиза не входят.

- `docker/` — Dockerfile-ы
- `scripts/` — скрипты запуска, миграций, деплоя
- `ci/` — вспомогательные скрипты для CI

Заполняется по мере необходимости в конкретном проекте.
